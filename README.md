## 🌟 Overview

**Project Chhaya** is the 24/7 autonomous cloud-shadow mirror and mobile multi-agent headquarters for **Chamunda Automobile Enterprise** (Royal Enfield Specialist Workshop, Radhanpur Road, Mehsana, Gujarat).

It unifies **20 autonomous laptop agents** into a single, high-speed mobile command center that runs 24/7, works online and offline (via PWA), self-heals dropped tunnels, automatically blocks cyber threats, and synchronizes state seamlessly.

## 🚀 Run Directly from GitHub

### Option 1: 1-Click Cloud Run in GitHub Codespaces
Click the badge below to spin up a fully functioning cloud instance in 60 seconds:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/thakoralpesh3/chamunda-re-enterprise)

Port `8081` will automatically forward with public visibility so the mobile web app opens in your browser immediately.

### Option 2: Docker Container
```bash
# Clone the repository
git clone https://github.com/thakoralpesh3/chamunda-re-enterprise.git
cd chamunda-re-enterprise

# Run via Docker Compose
docker compose up -d

# Check health
curl http://localhost:8081/api/health
```

### Option 3: Local Python Execution
```bash
git clone https://github.com/thakoralpesh3/chamunda-re-enterprise.git
cd chamunda-re-enterprise

pip install -r requirements.txt
python3 cloud_mirror_server.py
```
Open **`http://localhost:8081`** in your browser.
